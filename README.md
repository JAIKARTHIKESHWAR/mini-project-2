  Perfume Customization & Recommendation AI 

  

“Smell speaks louder than words — let AI choose your signature scent.”

--Overview

This project is an AI-powered Perfume Customization and Recommendation System that helps users discover, personalize, and design perfumes tailored to their personality, preferences, and occasion.
It provides an interactive and visually stunning UI/UX, ensuring a premium experience that feels like a real perfume boutique — but smarter!

The system uses Machine Learning to recommend perfumes based on user input (mood, gender, season, personality traits, etc.) and also lets users customize their own perfume blends virtually.

-- Key Features

- AI-Based Recommendation Engine – Suggests the perfect perfume based on user mood, preferences, and personality.

- Perfume Customization Studio – Allows users to mix and match top, heart, and base notes to create unique fragrances.

- Real-Time Preview – Displays personalized perfume cards and design visuals dynamically.

- Mood-to-Scent Mapping – Smart mapping between emotional states and scent families (floral, woody, oriental, fresh, etc.).

- Modern & Responsive UI – Sleek interface built with modern web design principles for smooth UX across all devices.

- Recommendation History – View and revisit previously suggested perfumes.

- Interactive Chatbot (Optional) – AI assistant to guide users through customization and answer perfume-related queries.
